A list of ideas for the project.

- Star systems start from a protoplanetary disc.

- Planets absorb from the protoplanetary disc.

- Heavier planets absorb the protoplanetary disc faster.

- Planets can spawn in a protoplanetary disc.

- Planets tug on each other. A gas giant will absorb or eject nearby planets.

- If planets tug on each other, this effect will be minimal over time.

- Planets have atmospheres.

- Planets have lithospheres (or whatever you call their cores, mantles, etc...)

- Planets have compositions.

- Planets have temperatures.

- The star can change radius, luminosity, brightness, etc over time

- Export simulation data as CSV (or print as table)

- Stop using `random` as a parameter
