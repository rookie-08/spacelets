# Roadmap

### v0.0: Project Creation (11/6/2026 - Current)
Create scaffolding for a Java project and create documents for
tracking the status of this project.

### v0.1: Simulation Creation (Developing)
A system can be created, consisting of a protoplanetary disc and a
celestial body (the star). There are no simulations, graphics, etc
yet. A simulation can be run on it, meaning that the simulation can
have methods like "tick()" or "stop()."
